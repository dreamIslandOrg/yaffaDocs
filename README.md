# הצלבת שוברים – דרים איילנד

מסך שמעלים אליו את דוח איזי גו ואת דוחות הספקים (קבצים או טבלאות שהועתקו מהאתרים),
בוחרים תאריך הגעה, ומקבלים: מה אומת (לפי סוג חבילה), אי-התאמות, חסרים, לא הגיעו,
חריגות והתרעות – וקובץ אקסל להורדה.

## התקנה ראשונה ב-Windows
1. להתקין Python מ-https://www.python.org/downloads/ – במסך הראשון לסמן **Add python.exe to PATH**.
2. להתקין Git מ-https://git-scm.com/download/win (ללחוץ Next עד הסוף).
3. לפתוח את "Command Prompt" (שורת הפקודה) ולהדביק:
   ```
   cd %USERPROFILE%\Documents
   git clone https://github.com/<שם-המשתמש>/dream-recon.git
   ```
4. להיכנס לתיקייה `Documents\dream-recon` וללחוץ לחיצה כפולה על `run.bat`.
5. במסך, בצד: "הגדרות" – להזין את סיסמת הקובץ של אתר חבר וללחוץ "שמירה" (נשמר רק במחשב הזה).

## עדכון לגרסה חדשה (Windows)
לחיצה כפולה על `update.bat`.

## מק
`cd ~/Downloads/dream-recon && bash run.command`

## גישה ממחשבים אחרים במשרד
כשהמערכת רצה, בחלון השחור מופיעה כתובת `Network URL: http://...:8501` – פותחים אותה בדפדפן בכל מחשב באותה רשת.

## מבנה
- `app.py` – המסך
- `core/readers.py` – קריאת קבצים (CSV בכל קידוד, אקסל, אקסל/זיפ מוגן סיסמה)
- `core/normalize.py` – הפיכת כל דוח לטבלה אחידה (כולל דוח איזי מודפס שהועתק מהמסך)
- `core/categorize.py` – סיווג שם חבילה לסוג חבילה
- `core/matcher.py` – ההצלבה (לפי מספר שובר בלבד, מול כל איזי)
- `core/report.py` – יצוא לאקסל
- `suppliers/*.yaml` – קובץ הגדרות לכל ספק. **ספק חדש = קובץ YAML חדש**, בלי לשנות קוד.
- `config/secrets.yaml` – סיסמאות, נוצר מהמסך, **לא עולה ל-Git**.

## כללים
- לעולם לא להעלות ל-Git קבצים עם נתונים אמיתיים. בתיקיית `samples` – רק דוגמאות מומצאות.
