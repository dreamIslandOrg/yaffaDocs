# הצלבת דוחות ספקים מול איזי

דף שרץ בדפדפן. כל הקבצים נקראים בתוך הדפדפן ולא נשלחים לשום מקום.

## מה יש כרגע
- `index.html` – דף בדיקה: מעלים דוח איזי ורואים את הטבלה האחידה והחריגים.
- `js/csv-parser.js` – קריאת CSV (כולל טיפול בשמות כמו בע"מ שבורים).
- `js/easy-config.js` – כל הכללים של דוח איזי (עמודות, חברות פנימיות, סיווג).
- `js/easy-normalize.js` – הפיכת דוח איזי לטבלה האחידה.
- `samples/easy-sample.csv` – דוח איזי מומצא לבדיקה (בלי נתונים אמיתיים).

## חשוב
לעולם לא מעלים ל-Git דוחות אמיתיים. הקובץ `.gitignore` חוסם קבצי csv/xlsx מחוץ לתיקיית samples.
